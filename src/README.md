# src

The code.

This directory exists because the house standard puts the code in `src/`, and
because an empty directory does not survive a git clone — a repository that
is checked out fresh would otherwise be missing the directory the standard
requires.

Put the source here. The exact layout inside is the project's own business;
`AGENTS.md` is where it is written down.

For the golden repository itself there is no product code, and there does not
need to be: the product here is the standard, and it lives in `scripts/`,
`docs/` and `templates/`.
